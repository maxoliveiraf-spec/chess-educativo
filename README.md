# ♟️ Xadrez Educativo

Um jogo de xadrez completo e educativo desenvolvido em JavaScript puro, perfeito para aprender a jogar xadrez de forma divertida e interativa.

## 🎮 Funcionalidades

- ✅ **Todas as 32 peças** com movimentos corretos
- ✅ **Regras completas do xadrez** incluindo:
  - Xeque e Xeque-mate
  - Roque (kingside e queenside)
  - En Passant
  - Promoção de peão
  - Detecção de empate (afogamento)
- ✅ **Interface educativa** com dicas progressivas
- ✅ **IA simples** para jogar contra o computador
- ✅ **Histórico de movimentos**
- ✅ **Peças capturadas**
- ✅ **Design responsivo** (funciona em desktop e mobile)
- ✅ **Modal com regras completas** para iniciantes

## 🚀 Como Jogar

1. Clique em uma peça branca para ver seus movimentos possíveis (destacados em verde)
2. Clique em uma casa destacada para mover a peça
3. A IA (pretas) fará seu movimento automaticamente
4. Capture as peças do oponente e faça xeque-mate para vencer!

## 🛠️ Tecnologias

- HTML5
- CSS3 (com design moderno e responsivo)
- JavaScript puro (sem frameworks)
- Emojis Unicode para as peças

## 📚 Regras do Xadrez

O jogo inclui um modal completo com todas as regras do xadrez, incluindo:
- Objetivo do jogo
- Movimentos de cada peça
- Conceitos importantes (xeque, xeque-mate, empate)
- Dicas para iniciantes

## 🎯 Objetivo Educativo

Este jogo foi desenvolvido com foco educativo, incluindo:
- Dicas que mudam conforme o progresso do jogo
- Destaque visual dos movimentos válidos
- Feedback imediato sobre o estado do jogo
- Interface intuitiva e amigável
